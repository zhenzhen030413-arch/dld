1.我对 FDE 的理解:FDE是一套闭环系统。首先从用户得到产品需求，其次FDE工程师需要把模糊的需求转化为清晰的任务需求，并对此开发可以解决的产品模型，再获取API等数据内容形成互联，再通过用户反馈进行迭代，后面过程类似网页部署。
2.Git 和 GitHub 的区别：git相当于一个需要在本地运行的软件，但是github像一个云端储存的网页。
3.今天掌握的概念：Repository：是一个可以包含代码的文件夹
Branch：是主分支下面的分支，用于复制主分支代码和内容，确认跑通以后可以迭代主分支内容更加方便。
Commit：提交，上传文档
Pull Request：这个方便工作组成员查看已经更改的内容方便修改迭代
Merge：把branch分支的内容合并到主分支上
4.今天运行的命令：主要按照github教程进行了分支创建，pull request修改
5.还不懂的地方：没太懂merge部分合并主分支的意思。
