## 2. 基本概念

Python代码：写的一整套指令文本，后缀`.py`的文件。告诉计算机要做什么，比如打印文字、读取路径、判断文件是否存在。计算机看不懂人说的中文，只能看懂这套代码。

Python解释器：把你写的 Python 代码，翻译成 CPU 能看懂的机器语言，让电脑真正执行代码。你在 VSCode 点运行、终端敲`python xxx.py`，就是调用这个解释器干活。

终端：用于接受代码命令，框命令窗口（VSCode 下方的 Terminal）。可以在这里输入命令：运行 py 脚本、输入数据，程序输出结果也打印在这里。

变量：用来存数据的 “盒子”。

字符串：文本文字类型

布尔值：只有两个值：`True`（真） / `False`（假），专门用来做判断。

条件判断：`if / elif / else`这套语法。根据布尔真假，选择执行哪一段代码。

代码缩进为什么重要：Python通过缩进划分代码区块，，缩进错误会语法报错
